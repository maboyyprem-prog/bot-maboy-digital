# Maboyy Digital Bot

**Versi aktif:** v15.7

## v15.7 — Buyer Transaction Menu Upgrade

Alur transaksi pembeli dibuat lebih jelas dan profesional tanpa mengubah mekanisme stok/fulfillment.

### Checkout baru
- Ringkasan pesanan yang lebih rapi.
- Progress: Ringkasan → Pembayaran → Selesai.
- Tombol langsung:
  - 💳 Lanjut ke Pembayaran
  - 📝 Catatan Pesanan
  - 🎟️ Voucher
  - 🔢 Ubah Jumlah
  - ❌ Batalkan
- Catatan dan voucher tetap tersimpan saat kembali dari menu pembayaran ke ringkasan.

### Menu pembayaran
- Saldo Kamu.
- QRIS Manual.
- Transfer Rekening jika aktif.
- QRIS Otomatis jika aktif.
- Voucher dan Catatan tetap bisa diubah.
- Bisa kembali ke Ringkasan atau membatalkan checkout.

### Setelah order dibuat
- 📤 Kirim Bukti Pembayaran.
- 🔄 Cek Status.
- 🧾 Detail.
- ❌ Batalkan Pesanan.
- 💬 Hubungi Owner.
- 🧾 Pesanan Saya.
- 🏠 Menu.

QRIS otomatis mendapat menu status/detail yang sama tanpa tombol bukti manual.

### Pembayaran saldo
Setelah sukses tersedia tombol langsung ke Detail Pesanan.

Tidak ada Railway Variable baru.
